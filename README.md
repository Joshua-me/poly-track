# poly-track

Simple personal-use browser prototype inspired by PolyTrack's low-poly neon style.

This version uses six original handcrafted starter tracks and tighter arcade handling intended to feel closer to the source material without copying its content.

## Run

Open `index.html` directly in a browser, or serve the directory with a static file server.

## Controls

- `W` / `Up`: accelerate
- `S` / `Down`: brake
- `A` / `Left`: steer left
- `D` / `Right`: steer right
